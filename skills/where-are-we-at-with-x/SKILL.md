Where are we at with X? Find X in branches, PRs, issues, commits and docs,
say which match you picked, and tell me whether it is shipped, in progress,
stalled (since when), abandoned or never started. Then, for that work:

1. What is happening right now, and when it was last touched.
2. A checklist of what is already done.
3. A checklist of the next steps (skip if shipped).
4. An overview of the goal.

Back each done item with a commit and each next step with where it came from,
or mark it inferred. If nothing matches X anywhere, say so in one line.
